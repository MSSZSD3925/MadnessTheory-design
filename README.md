# 癫狂构想 · 设计与现状

> **➡️ 直接看网页版：[msszsd3925.github.io/MadnessTheory-design](https://msszsd3925.github.io/MadnessTheory-design/)**
>
> 别在 GitHub 里点文件看源码——看网页版才是读它的方式。

《癫狂构想》（MadnessTheory）是一个关于情绪的 Minecraft 模组。
本仓库只放**设计站**，不放源码。

## 两个部分

打开网页版会看到两栏：

**设计分册**（`design/`）—— 手写的，取自已定稿的设计记录。
写了这个模组想做什么、机制怎么运转、还有哪些没定。

**现状**（根目录那些页）—— 从源码生成，记录代码现在实际是什么样。
跟设计分册有出入是正常的：设计在前，代码在后。

## 从哪开始读

如果你只想知道这是个什么东西，看 [设计分册 · 总览](https://msszsd3925.github.io/MadnessTheory-design/design/)。

如果你想知道玩家第一小时在干什么，看 [从零开始的路](https://msszsd3925.github.io/MadnessTheory-design/design/progression.html)。

## 说明

- 站里所有内容都是设计稿，不是最终成品，数值会变。
- 写着「待定」的地方是真的还没定，不是漏写。
- 页面是纯静态的，直接打开 html 就能看，不需要服务器。
