# 设计意图（手写层）

这一层与站点其它页面不同：**其它页面全部由代码生成**，回答"现在长什么样"；
这里回答"**为什么这么定**"—— 也就是代码里看不出来的那部分判断。

## 命名约定

放在本目录下，文件名决定它挂到哪个条目：

| 文件名 | 对应 |
|---|---|
| `kind-<id>.md` | 某雕像种类，如 `kind-chorus.md` |
| `attr-<id>.md` | 某属性，如 `attr-void.md` |
| `trait-<NAME>.md` | 某特性，如 `trait-PURPUR.md` |
| `mood-<id>.md` | 某心绪，如 `mood-joy.md` |
| `ritual-<名字>.md` | 某仪式，如 `ritual-sublimation.md` |
| 其它任意名 | 会被列在"其它"里 |

写完重跑生成器，内容会出现在站点的「设计意图」页。

## 建议写什么

- **为什么是这个数**（而不是别的数）—— 尤其是"看着奇怪但有意为之"的那些
- **它在玩法上想达到什么效果**
- **已知的取舍与代价**
- **什么情况下应该重新考虑这条设计**

## 不需要写什么

- 数值本身（代码里就有，站点会自己读）
- 改了什么（那是 git 的事）
