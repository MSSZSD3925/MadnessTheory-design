设计分册/从零开始的路

从零开始的路

一个玩家从进入世界到第一次看见自己身上的刻度，要走过五段。

概览
模组定位让玩家真的感到愧疚，而不是看着数字
核心循环过日子 → 心绪 → 施法 → 记账 → 发作
阶段数五段走完，之后进入处理期
第一段入口三次环境提示 ＋ 上床入睡
痕迹出现第五段（攒够 counter 300 之后）
开工顺序十段，第一段是最小可玩内容

第一段 · 入梦

这一段是阶段指标：它只负责把玩家送进梦里一次，然后放他出来。

  1. 他在世界里拿到 3 次情绪提示（hintsNeededForDream，默认 3）。
  2. 第 3 次时给一条动作栏提示：「困意在夜里聚拢……也许该去睡一觉了。」——它只把 dreamReady 置真，不自动入梦，等他上床。
  3. 他上床 → 被拦下来 → 进入梦境（复用原版全部睡觉判定，problem == null 才进）。
  4. 他出现在一个由纯白方块构成的房间里（后期会参杂黑色方块）。
  5. 房间中央有一个讲台。
  6. 右键讲台 → 房间崩塌 → 向下坠落 → 掉到一定高度后回到原世界的床前。

这一段有三处可变要素，都以极端程度这一个数为标准：房间的构成、房间生成的高度（决定坠落时长）、右键讲台后的延迟。

待定房间的形态还没定死：按现在的流程，封闭空间不足以容纳大量不同要素，可能改成一块超大的平面。
设计约定梦境不直接送指南书。他拿到的是一本写了内容的成书，而那本书里提示了指南书的合成配方。所以梦境给的不是工具，是「你该怎么做工具」。

第二段 · 指南书从哪来

配方
八颗紫水晶围绕一本书 → 合成封书
拆封
用雕刻刀 ＋ 封书 双手右键 → 得到一本 3 点耐久的指南书

封书这个设计有它自己的理由：合成只得到封书，而封书不能撕、不能修——于是「撕一本新书」等于凭空造出撕下的纸那条路被切断了。

第三段 · 心绪：一步步提取

  1. 用书右键多方块仪式，一步步把心绪提出来。
  2. 中间有一步要用感知之杖把记录里的情绪释放出来，而那一步是进入下一步的前置条件。
  3. 之后需要再次入梦才能解锁下个阶段的内容。

第四段 · 两根杖

杖怎么来
感知之杖往雕像内部的台座里放一尊同类雕像（同类＝材质推出来的种类相同），然后用指南书右键。
情绪之杖成功提取出情绪结晶之后，用结晶右键「台座上放着感知之杖的那座雕像」→ 开一场 100 刻的绑定仪式 → 那柄杖变成绑定该心绪的情绪之杖。台座上若已是情绪之杖，那就是重绑。
已作废「把一个雕像放在同类雕像上方」是过期措辞。现在以「台座内含一尊同类雕像」为准，不是方块堆叠。

第五段 · 痕迹：你身上有一道刻度

这一段的定位是「用魔法」到「被魔法记账」的那一步，也是玩家第一次遇到不是他做的这件事。

触发：不是研究，是攒够

项规格
触发条件counter（四路痕之和）≥ 300 → 发作一次
解锁条件没有。它是被攒出来的
大概什么时候到约 50 次满蓄力的量（蓄力写 投入 ÷ 10）

这个位置是对的：它永远发生在你已经用得很凶之后。所以第五段的玩家不是新手，是一个已经上了手、正在加码的人。

第一次发作不做特殊处理

按已定的那套走：随机、事件型、5 秒、按四级后果。不指定它发生在哪、不挑时刻、也不给它加物证。

硬约束惩罚不许拿走玩家的物资。所以「拆家」「吸走箱子里的东西」这一类提案本身就不该出现。

那一页指南书是发作之后才出现的

研究树里多一个节点，而那一页写的不是答案，是一件东西的做法——查询物的合成。

动线是先遇到 → 再拿到那个能看的东西，而不是先看数字再明白。这个模组不给你数字，它给你一件要你自己做出来的、拿在手上的东西。

终点：手持它右键，四根管子浮在面前

它是手持物品，默认零显示，手持查询物才看到。

你在管子上看到什么它是
液面可消退
管身一条刻度线危险区的入口
裂痕不可逆（一道一点，最多 25 道）

它给形状不给数字，所以你看得见「多高」，看不见「多少」。第五段的分量在于：你已经攒了很久，而这是你第一次能看见它长什么样。

设计约定这一段最后要留给玩家自己想的一句话是「你可以继续。」——因为模组不阻止他，只让他看见。

之后 · 处理期

第五段之后，玩家要开始「处理」它。而处理只有三条路，三条都比他想的更贵。

路它是它为什么更贵
埋痕把痕埋进一块地里那块地就永久脏了，而你不能再走上去
苦修把自己压下去（上限 100、效率 −50%）你变弱了，而痕只是不再涨
麻木把自己弄钝（每点 −0.2% 入账）你不再难受，而那是不可逆的

三条路都不是「解决」，是「换一种代价」。再往后才是这些代价开始互相咬的地方：六绪轮、四门、维度。

开工顺序

排法只有一个原则：每一段做完都是一个更完整的游戏，而不是等最后一段才好玩。所以第一段不叫地基，它叫最小可玩内容。

段做什么验收
零音效层（三步最小管线）游戏里能听到一个属于本模组的声音
一最小可玩的一圈：法杖只做瞬发、心绪条、个人账可消退 ＋ counter、发作只做最轻两级后果从零玩半小时，能感到「我用魔法，它在我身上记账，账满了会出事」
二把代价补全：场地账、不可逆档、四级后果全开、愈合你会开始怕自己的账
三加蓄力与驻场三种方式手感不同，写的账也不同
四加六场正面小仪式结构判定 ＋ 展示物 ＋ 结算这条链跑通
五加末影角与平衡环（五零件）四门要用的两块前置就位
六加四门大魔法（三场）魔法的终局完整
七加六绪轮与读数台圈能跑起来
八加情绪维度与采集能去另一个世界拿材料
九建材（可与任意一段并行）瓶颈是美术不是代码
十麻木之地与十二件麻木装备五条线的总终点

三条贯穿全程的规矩

  1. 每一段结束都要能玩。任何一段做完，玩家都应该能在游戏里多做出点什么。
  2. 别提前做样子。雕像的朝向、展示物、花纹看着像摆拍，其实是判定的一部分；哪一段做仪式，就在那一段把判定写实。
  3. 数写死在一处。数值都在设计记录的附录乙，改一处就改那一处，不要散进代码里变成第二份口径。
